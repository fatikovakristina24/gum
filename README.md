# Unbounded — Жвачка для глаз

Откройте `index.html` в браузере. Все изображения и шрифты находятся в папке проекта; подключение к интернету не требуется.

Сайт написан только на HTML и CSS, без JavaScript и без сборки. Верстка адаптируется к экрану: основные макеты — 1440, 768 и 414 пикселей.

## Файлы

- `index.html` — содержимое и разделы сайта.
- `styles.css` — основные стили.
- `responsive.css` — стили планшета и телефона.
- `tester-states.css` — переключение начертаний в пробе шрифта.
- `assets/` — иллюстрации из макета Figma.
- `fonts/` — локальные шрифты Unbounded и Inter, а также их лицензии.

В разделе «Попробуй свой текст» можно написать свою фразу и выбрать одно из восьми начертаний. Переключение работает средствами HTML и CSS. Поле текста и выбор начертаний доступны с клавиатуры.
